# 시연 체크리스트

README의 시연 캡처를 만들 때 쓰는 순서다. 결과가 매번 같도록 fixture 모드(`.env`의 `API_MODE=FIXTURE`, 기본값)로 진행한다.

## 준비

```bash
python -m uvicorn src.api:app --port 8000     # --reload는 쓰지 않는다 (변경을 놓친 적 있음)
```

브라우저에서 http://localhost:8000 을 연다. 캡처는 `docs/screenshots/`에 아래 파일명으로 저장한다.
